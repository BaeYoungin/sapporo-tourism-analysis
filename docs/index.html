Method

데이터 수집 방법

수집 파이프라인

  • 대상 · 삿포로 관광협회 공식 사이트 관광시설 132곳
  • Firecrawl · 일본어 상세페이지(운영정보) + 한국어 페이지(명칭·설명) 스크래핑
  • WP REST API · 사이트가 직접 부여한 공식 분류(카테고리/지역/계절) 매핑
  • 저장 · 원본 캐시(JSON) + 분석용 CSV sapporo_spots.csv
수집 값은 사이트 원문 그대로이며, 임의 생성·보정한 데이터는 포함하지 않습니다.

Caveats

데이터 한계와 유의점

  • 운영시간·요금 미기재가 많음(각 36·31곳) — 사이트가 상세 정보를 공식 홈페이지로 위임
  • 일부 시설은 한국어 번역이 제공되지 않아 명칭이 일본어로 표기됨
  • 카테고리는 사이트의 공식 분류를 그대로 사용했으며, 한 시설이 복수 분류에 속함
  • 수집 시점 기준 데이터로, 운영시간·요금은 변동 가능
  • 본 자료는 교육·분석 목적이며, 원문·이미지의 무단 재배포는 지양하고 출처를 명시함
재현: python crawler.py → python analyze.py → python build_deck.py
